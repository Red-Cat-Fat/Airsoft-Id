О проекте Airsoft ID

Airsoft ID — это платформа для страйкбольного сообщества, которая помогает игрокам, командам и организаторам взаимодействовать в едином цифровом пространстве.

Наша цель — сделать участие в играх проще: от поиска единомышленников до ведения профиля, достижений и активности в комьюнити.
