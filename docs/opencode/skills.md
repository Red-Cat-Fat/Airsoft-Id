# Подключённые OpenCode Skills

Установлены в `.opencode/skills/` из [awesome-opencode-skills](https://github.com/TheArchitectit/awesome-opencode-skills).  
Автоматически загружаются OpenCode при запуске в этом проекте.

---

## 📄 Document Processing

### document-docx
**Создание и редактирование Word-документов**
- Работа с отслеживанием изменений, комментариями, форматированием
- Извлечение текста, создание новых документов
- **Пример:** «Создай отчёт в docx на основе данных из таблицы»

### document-pdf
**Манипуляции с PDF: извлечение, создание, слияние**
- Извлечение текста и таблиц, заполнение форм
- Объединение/разделение PDF, водяные знаки, пароли
- **Пример:** «Объедини эти PDF в один файл» / «Извлеки таблицу из PDF»

### document-pptx
**Работа с презентациями PowerPoint**
- Создание, редактирование слайдов, работа с макетами
- Добавление заметок докладчика, комментариев
- **Пример:** «Создай презентацию из 5 слайдов с этим содержанием»

### document-xlsx
**Работа с электронными таблицами**
- Создание таблиц с формулами и форматированием
- Анализ данных, визуализация, чтение CSV/TSV
- **Пример:** «Создай xlsx с расчётом бюджета на квартал»

## 🛠 Development & Code Tools

### artifacts-builder
**Сборка сложных HTML-артефактов**
- Создание многостраничных артефактов с React, Tailwind CSS, shadcn/ui
- Управление состоянием, роутинг
- **Пример:** «Создай дашборд с графиками как HTML-артефакт»

### changelog-generator
**Автоматическая генерация changelog из git-коммитов**
- Анализ истории коммитов, категоризация изменений
- Перевод технических коммитов в user-friendly формат
- **Пример:** «Создай changelog для коммитов за последнюю неделю»  
  **Пример:** «Сгенерируй релиз-ноуты для версии 2.5.0»

### mcp-builder
**Создание MCP-серверов для интеграции с внешними API**
- Гайд по созданию серверов на Python (FastMCP) или TypeScript (MCP SDK)
- Разработка инструментов для LLM
- **Пример:** «Создай MCP-сервер для интеграции с GitHub API»

### skill-creator
**Создание собственных OpenCode Skills**
- Генерация структуры скила (SKILL.md, скрипты, ресурсы)
- Создание повторяемых рабочих процессов
- **Пример:** «Создай скил для работы с нашим API бэкенда»

### staff-engineer-review
**Глубокое ревью кода на уровне Staff+ инженера**
- Оценка архитектуры, качества кода, тестового покрытия
- Проверка соответствия плану, производительности, безопасности
- **Пример:** «Проверь этот PR на архитектурные проблемы»  
  **Пример:** «Сделай ревью моего Merge Request'а»

### webapp-testing
**Тестирование веб-приложений через Playwright**
- Проверка фронтенда, дебаг UI, скриншоты, просмотр логов
- Работа с динамическими SPA (Angular, React, Vue)
- **Пример:** «Запусти тест для страницы логина»  
  **Пример:** «Проверь, что форма регистрации работает»

## 💼 Business & Marketing

### brand-guidelines
**Применение бренд-цветов и типографики OpenCode**
- Цветовая схема: Desert Tan `#C2B280`, Sand-Tactical `#A68A64`, Amber Accent `#FF8C00`
- Шрифты: JetBrains Mono для заголовков, system sans-serif для тела
- **Пример:** «Оформи этот документ в стиле нашего бренда»

### competitive-ads-extractor
**Анализ рекламных кампаний конкурентов**
- Извлечение объявлений из Facebook/LinkedIn Ad Libraries
- Анализ сообщений, креативов и целевой аудитории
- **Пример:** «Проанализируй рекламу конкурентов в Facebook»

### domain-name-brainstormer
**Генерация и проверка доменных имён**
- Создание креативных идей для доменов
- Проверка доступности в .com, .io, .dev, .ai и других TLD
- **Пример:** «Придумай домен для нового SaaS-продукта»

### internal-comms
**Написание внутренних коммуникаций**
- Статус-репорты, новостные рассылки, FAQ, отчёты
- Обновления для руководства, постмортемы
- **Пример:** «Напиши дайджест новостей компании за неделю»

### lead-research-assistant
**Поиск и квалификация лидов для продаж**
- Анализ продукта и поиск целевых компаний
- Стратегии аутрич-кампаний
- **Пример:** «Найди 10 компаний, которые используют AI-ассистентов»

## 🎨 Creative & Media

### canvas-design
**Создание визуальных артов в PNG/PDF**
- Постеры, дизайны, статические изображения
- Философия дизайна: от Concrete Poetry до Geometric Silence
- **Пример:** «Создай постер в минималистичном стиле»  
  **Пример:** «Нарисуй абстрактную композицию в стиле Organic Systems»

### image-enhancer
**Улучшение качества изображений и скриншотов**
- Повышение резкости, чёткости, апскейл
- Подготовка для презентаций, документации, соцсетей
- **Пример:** «Улучши качество этого скриншота для документации»

### slack-gif-creator
**Создание анимированных GIF для Slack**
- Валидация размеров и ограничений Slack
- Примитивы анимации: Bounce, Spin, Pulse, Explode, Morph
- **Пример:** «Сделай GIF с анимацией загрузки для Slack»

### theme-factory
**Применение цветовых тем к артефактам**
- 10 встроенных тем (Ocean Depths, Sunset Boulevard, Desert Rose и др.)
- Применение к слайдам, документам, HTML-страницам
- **Пример:** «Примени тему Desert Rose к этой презентации»

### video-downloader
**Скачивание видео с YouTube и других платформ**
- Сохранение для офлайн-просмотра, архивирования, монтажа
- Поддержка различных форматов и качества
- **Пример:** «Скачай это видео с YouTube в MP4 1080p»
